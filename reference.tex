\subsection{Upper and lower bound}
\paragraph{-} \verb|upper_bound(a.begin(), a.end(), k)|: Returns an iterator for the first element $e$ that is \textbf{strictly greater} than $k$. In other words, $e > k$.

\paragraph{-} \verb|lower_bound(a.begin(), a.end(), k)|: Returns an iterator for the first element $e$ that is \textbf{greater or equal} than $k$. In other words, $a \geq k$.

Note: never use it over a set. Set has it's own implementation as a method: \verb|set::lower_bound(k)|.

\subsubsection{How to use it}

\paragraph{-} \verb|o_set::order_of_key(k)|: Gets the number of elements that are \textbf{strinctly smaller} than $k$. $e < k$. If $k$ is greater than every element in the set, then it returns \verb|set.size()|.

\paragraph{-} \verb|o_set::find_by_order(n)|: Returns an iterator to the $n$-th element counting from zero. That is, gets the element that has a \verb|order_of_key| of $n$. If no such element exists, i.e. the requested element is too big, then \verb|set.end()| is returned.

\subsection{Bitwise}
\subsubsection{Properties}
$$
\begin{array}{rl}
a | b &= a \oplus + a \& b \\
a \oplus (a \& b) &= (a|b)\oplus b \\
b \oplus (a \& b) &= (a | b)\oplus a \\
(a \& b) \oplus (a|b) &= a\oplus b
\end{array}
$$
\subsubsection{Equations}
$$
\begin{array}{rl}
 a+b &= (a|b)+(a \& b) \\
 a+b &= a\oplus b + 2(a \& b) \\
 a-b &= (a \oplus(a \& b))-((a|b)\oplus a) \\
 a-b &= ((a|b)\oplus b) - ((a|b)\oplus a) \\
 a-b &= (a \oplus (a\& b)) - (b \oplus (a \& b)) \\
 a-b &= ((a|b)\oplus b) - (b\oplus (a\&b))
\end{array}
$$
